One-Click Setup & Integration Guides 
from openai import OpenAI

# Initialize client with your 24/7 Qwen Studio Server
client = OpenAI(
    base_url="http://127.0.0.1:5000/v1",
    api_key="sk-qwen-local"
)

# Streaming chat completion with flagship Qwen4-Max
stream = client.chat.completions.create(
    model="qwen4-max",
    messages=[
        {"role": "user", "content": "Explain quantum computing in 2 paragraphs."}
    ],
    stream=True
)

for chunk in stream:
    if chunk.choices and chunk.choices[0].delta.content:
        print(chunk.choices[0].delta.content, end="", flush=True)
print()

NextChat (ChatGPT-Next-Web) Setup:

  1. Open NextChat settings (Bottom-left gear icon ⚙️).
  2. In Model Provider, select OpenAI.
  3. In Endpoint (Base URL), enter: http://127.0.0.1:5000/v1
  4. In API Key, enter: sk-qwen-local
  5. In Custom Models, add: qwen4-max,qwen3.8-max,qwen3.7-plus,qwen3.8-omni-flash
  6. Done! All chats will now route through your 100% free authentic Qwen Studio server.

Cursor IDE / VS Code Continue Setup:

  1. Open Cursor Settings → Models.
  2. Enable OpenAI API Key.
  3. Check Override OpenAI Base URL and enter: http://127.0.0.1:5000/v1
  4. Enter API Key: sk-qwen-local
  5. Add Model: qwen4-max or qwen3.8-max.
